# 四级单词小窝

英语四级背单词网页：阅读时自动标出四级词汇、点词收进生词本、多义词分场景释义、9 种测验、自定义背景。

- 打开一次后，所有内容都缓存到手机里，**断网也能用**
- 可以「添加到主屏幕」，像 App 一样使用
- 不需要注册账号，学习进度保存在各自的设备上

## 学生怎么用（iPhone）

1. 用 **Safari** 打开网址（微信里点右上角「…」→「在 Safari 中打开」）
2. 点底部分享按钮 →「添加到主屏幕」→「添加」
3. **联网状态下**从桌面图标打开一次，等右上角显示「已可离线使用」
4. 以后断网也能从桌面图标打开。记得定期在「我的」页面导出进度备份

## 文件说明

| 文件 | 作用 |
| --- | --- |
| index.html | 应用本体 |
| cet4.json | 四级词库（4995 词，含例句、真题原句、搭配） |
| dict.json | 通用英汉词典（查非四级词用） |
| articles.json | 内置 100 篇文章 |
| scenes.json | 138 个多义词的分场景释义 |
| sw.js | 离线缓存脚本 |
| manifest.webmanifest、icons/ | 主屏幕图标与名称 |

## 更新内容

替换文件后，打开 `sw.js`，把 `VERSION` 改成新的值再提交。学生下次联网打开时会自动更新。

词库来源：kajweb/dict、KyleBing/english-vocabulary、ECDICT。
